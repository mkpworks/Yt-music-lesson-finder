Embed

Use the finder on another site

Add this markup. The script loads the catalog from this site, draws inside a shadow root, and does not restyle the host page.

<div id="lesson-finder"></div>
<script src="https://mkpworks.github.io/Yt-music-lesson-finder/embed.js" defer></script>

Optional attributes: data-theme (light or dark), data-accent (a hex color), and data-height (a max height). data-channel, data-instrument, data-style, data-tradition, data-topic, data-structure, data-level, and data-in-the-style-of preset those filters. Any element with data-lesson-finder mounts too. Call LessonFinder.mount(element, options) for the same options in script.
